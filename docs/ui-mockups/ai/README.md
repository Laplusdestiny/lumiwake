# AI 候補機能の UI モック

claude.ai で作成した「Lumiwake AI振り分け 画面モック」（2026-10-02 版）を静的 HTML に展開したもの。
ブラウザで開くと 1280×800（設定画面は 1280×880）の画面が表示される。見た目の確認用で、ボタン等は動かない。
アクセントカラーは既定の青（#6cb2ff）。モックでは緑（#7fd1b9）・紫（#c9a2ff）・橙（#f2b45a）にも切り替えられる想定だった。
フォントは Google Fonts（IBM Plex Sans JP / JetBrains Mono）を読み込んでいる。

| ファイル | 画面 | 概要 |
| --- | --- | --- |
| `1-strip-local.html` | 候補ストリップ型（`local`） | プレビュー下に上位 3 件の候補カード（割り当てキー・フォルダ名・フルパス・一致度）。スコアは「一致度（確率ではありません）」と表記。右に細いキー割り当て一覧 |
| `2-strip-systemone.html` | 候補ストリップ型（`systemone`） | 候補カードは確率（%）表示。「該当なし」カードを Space に対応。ヘッダーに外部送信中の表示、プレビューと候補の間に未評価フォルダの再診断案内の帯（Ctrl+Shift+D） |
| `3-settings.html` | 設定 › AI 候補 | バックエンド選択、ローカル設定、System One 互換 API 設定（エンドポイント・API キーの環境変数と検出状態・画像上限・しきい値・接続テスト・外部送信の同意状態）、候補数と先読み枚数、振り分け先ごとの説明文・的中率・外部送信の除外、再診断キー、診断キャッシュ |
| `future-batch-review.html` | **将来案：一括確認画面（当面実装しない）** | 確信度の高い画像をまとめて移動する画面。要件定義書の未決事項として残しているだけなので、実装対象にしないこと |

## 注意

- `docs/ui-mockups/` 直下の旧モック（`A-sidebar.html` の AI 候補パネル、`C-batch-review.html`）は古い案。AI 有効時の仕分け画面はこのフォルダの候補ストリップ型が正しい。
- 「該当なし」カードを Space に対応させる点は、開発者の確認が取れていない（`docs/ai-suggestion-handoff.md` の未決事項を参照）。
- モック内の数値（件数・スコア・的中率など）とフォルダ名はダミー。
