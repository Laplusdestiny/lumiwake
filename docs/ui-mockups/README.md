# UI モック

claude.ai で作成したモックを静的 HTML に展開したもの。ブラウザで開くと 1280×800 の画面が表示される（見た目の確認用で、ボタン等は動かない）。
アクセントカラーは既定のアンバー（#e8a33d）。モックでは青（#6aa5e8）・緑（#7cc49a）にも切り替えられる想定だった。
フォントは Google Fonts（Zen Kaku Gothic New / JetBrains Mono）を読み込んでいる。

| ファイル | 画面 | 概要 |
| --- | --- | --- |
| `A-sidebar.html` | A. サイドバー型（デフォルト） | 中央に大きなプレビュー、右に AI 候補（最大 3 件・確信度バー）と 1–9 キーの振り分け先リスト（フルパス付き）、下に直近のフィルムストリップ |
| `B-focus.html` | B. フルスクリーン集中型 | 画像全面表示＋オーバーレイで大きな候補カード 3 枚とキーヒント |
| `C-batch-review.html` | C. 一括確認（AI 機能追加後） | グリッド表示。確信度 80% 以上を自動選択してまとめて移動、低いものは「要確認」 |
| `D-settings.html` | 設定 | キーとフォルダの割り当て、AI 候補数・最低確信度、推論の実行場所（ローカル／外部 API）、対応形式 |

## 注意

- AI 候補の表示は拡張計画の機能。MVP では AI パネルなしのサイドバー型から作る
- ヘッダーの表記は「画像振り分け」だが、アプリ名は Lumiwake に決定済み
- 設定画面の対応形式表記は古い。正しくは要件定義書の対応形式（JPEG / PNG / WebP / GIF / BMP / TIFF / AVIF / HEIC）
- 使い方としては、A または B で 1 枚ずつ仕分け、たまった画像を C でまとめて処理する流れを想定
