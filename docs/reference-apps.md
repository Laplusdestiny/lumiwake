# 参考アプリの調査

新アプリの設計の参考にした、Windows 向けの既存の画像仕分けツール 2 本（どちらも Vector で公開、更新は止まっている）。

## Typict（作者: Karno）

- 「見る → キーを押す → 次へ」の流れに特化した操作
- A–Z / 0–9 のキーにフォルダを割り当てて振り分け
- 画像の先読みとサムネイルプレビューで待ち時間を減らす
- 「予約してから一括実行」の 2 段階方式で、押し間違いによる移動を防ぐ
- 移動／コピーの切り替え、Shift+Ctrl による複数フォルダへの同時割り当て、リネーム予約
- Susie Plugin による形式拡張

## 月鏡（作者: TaiL）

- フォルダ移動型と、チェックリスト（タグ）型の 2 つの分類方式。タグ型では 1 枚の画像を複数の仮想カテゴリに入れられる
- 最大 4,096 段の Undo
- サブフォルダの自動検出
- マウスジェスチャ、ビューア・変換機能も豊富

## Lumiwake に受け継ぐ設計思想

1. キーとフォルダの即時対応（キー 1 つで振り分け）
2. 表示の先読みによる速さ
3. 安全網（予約方式または深い Undo）→ Lumiwake では複数段 Undo と削除予定方式を採用
4. サブフォルダの自動検出とキーの自動割り当て

AI 拡張では、月鏡のタグ型の考え方と、Typict の「予約→実行」の流れが「AI が提案 → ユーザーが確認」のパターンに自然につながる。
