# 一覧ビュー（Issue #12）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 読み込んだ画像を一覧（グリッド）で見渡し、選んだ画像を 1 枚表示の「現在の画像」にして振り分けられるようにする。

**Architecture:** Rust に一覧用のサムネイル専用 LRU キャッシュ（長辺 480px、デコードの同時実行数を制限）と `lumi://grid/{gen}/{index}` ルート、全画像の状態を返す `list_items` コマンドを足す。画面は新しい `Screen = "grid"` を `src/views/grid.ts` に作り、既存の `actions.jumpTo` で仕分け画面へ戻す。一覧を開くキー `[keys] toggle_grid` を設定に追加する。

**Tech Stack:** Tauri 2 / Rust（`image` クレート）、素の TypeScript + Vite、vitest + happy-dom

**Spec:** `docs/superpowers/specs/2026-11-05-grid-view-design.md`

## Global Constraints

- ユーザーの画像ファイルを失わせない。一覧画面ではファイル操作（振り分け・削除・スキップ）のキーを受け付けない
- テストでは一時ディレクトリのダミー画像だけを使う（`decoder::tests::write_dummy`）
- UI 文言は日本語。コメントもこのリポジトリの書き方（日本語、です・ます調でない短い文）に合わせる
- WebView には任意のパスを渡さず「generation＋画像番号」だけを渡す
- 一覧のキー既定値は `Ctrl+Shift+L`（`Ctrl+Shift+G` は WebView の検索の予約キー）
- 一覧用サムネイル: 長辺 `GRID_THUMB_MAX = 480`、キャッシュ容量 `GRID_CACHE_CAPACITY = 1000`、同時デコード数 `GRID_DECODE_LIMIT = 3`
- タイルの幅: 96〜360px、段階 `[96, 160, 240, 360]`、既定 160、`localStorage` のキー `lumiwake.gridTile`
- 処理済みを開こうとしたときの文言: 「この画像はすでに振り分け済みです（取り消しで戻せます）」
- コミットごとに `cargo fmt --check`・`cargo clippy --all-targets -- -D warnings`・`cargo test`（`src-tauri/`）と `npm run typecheck`・`npm test` が通ること
- コミットメッセージは既存の形式（`Feat: …` / `Docs: …` ＋日本語）で、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. 絞り込みで選択中の画像が隠れた → 絞り込み結果の先頭を選択し、Enter でその画像を開く（隠れた画像を開かない）。Task 5 のテストで確認する
2. 画像が 0 枚／絞り込みで 0 件 → 「該当する画像がありません」を表示し、矢印・Enter で何も起きない（例外を出さない）。Task 5 のテストで確認する
3. `localStorage` に壊れた値（`"abc"`、`"9999"`、未設定）が入っている → 96〜360 に丸めるか、既定の 160 にする。Task 5 のテストで確認する
4. 一覧を開いている間に generation が変わった（設定で並び順を変えると generation が変わる） → 古い番号のまま開かず、一覧を閉じる。Task 5 のテストで確認する
5. 同名ファイルの確認中に一覧ボタンを押した → 一覧を開かない（確認ダイアログを優先する）。Task 6 のテストで確認する

**Interfaces:**

- Produces（Task 6 が使う）:
  - `openGrid(): Promise<void>` — セッションがない／`session.conflict` があれば何もしない。`listItems` を取得して `store.grid` に入れ、`store.screen = "grid"`、選択を `current ?? 最初の画像` にして `notify()`。失敗したらトーストを出して画面はそのまま

  - `handleGridKey(combo: string): boolean`（一覧本体にフォーカスがあるとき）

  - `handleGridAction(action: string, el: HTMLElement): boolean` — `grid-open`（`data-index`）、`grid-close`
  - `handleGridInput(el: HTMLInputElement): void` — 絞り込み欄（`data-grid="filter"`）とスライダー（`data-grid="size"`）
  - `handleGridWheel(e: WheelEvent): boolean` — Ctrl＋ホイールで 1 段階ずつ変える
  - 純関数（テスト用に export）: `TILE_STEPS = [96, 160, 240, 360]`, `clampTile(v: unknown): number`（数値でなければ 160、範囲外は 96〜360 に丸める）, `stepTile(size: number, dir: 1 | -1): number`（今より大きい／小さい次の段階、端では端のまま）, `gridColumns(width: number, tile: number, gap: number): number`（`Math.max(1, Math.floor((width + gap) / (tile + gap)))`）

**画面の決まりごと（スペックから）:**
- 骨組みは `root.dataset.view = "grid"` のときだけ作り直す。ヘッダー: 見出し「一覧」、`<input data-grid="filter" placeholder="ファイル名で絞り込み（Ctrl+F）">`、件数 `<span data-slot="grid-count">`（`12 / 340 枚`、絞り込みなしは `340 枚`）、`<input type="range" data-grid="size" min="96" max="360" step="8">`、閉じるボタン（`data-action="grid-close"`、title「元の画面に戻る（Esc）」）
- タイル: `<button class="grid-tile state-{state}" data-action="grid-open" data-index="{index}">` に `<img src="${lumiUrl(\`grid/${gen}/${index}\`)}" loading="lazy" alt="">`、ファイル名、ラベル（`moved` は `→{label}`、`deleted` は `削除予定`、`skipped` は `保留`）。現在の画像は `is-current`、選択は `is-selected`＋`aria-selected="true"`
- タイルは一覧を開いたときと絞り込みを変えたときだけ作る。選択の移動ではクラスを付け替えて `scrollIntoView({ block: "nearest" })` するだけ
- タイルの幅は CSS 変数 `--grid-tile`（`grid-template-columns: repeat(auto-fill, minmax(var(--grid-tile), 1fr))`、gap は定数 `GRID_GAP = 12` と CSS をそろえる）。変更したら `localStorage` の `lumiwake.gridTile` に保存し、スライダーの値もそろえ、選択中のタイルへスクロールする
- 0 件なら一覧の代わりに「該当する画像がありません」
- `renderGrid` で `store.grid.generation !== store.session.generation` なら `closeGrid()` する
- サムネイルを読めなかった `img` は `error` イベントで `icons.image` に置き換える

**キー（`handleGridKey`）:** Left/Right ±1、Up/Down ±列数、PageUp/PageDown ±列数×表示できる行数（`Math.max(1, Math.floor(一覧の clientHeight / (タイル幅 + 40)))`）、Home/End、Enter で開く、`Ctrl+F` で絞り込み欄にフォーカス、`Ctrl+Equal`・`Ctrl+Shift+Equal`・`Ctrl+Semicolon`・`Ctrl+Shift+Semicolon`・`Ctrl+NumAdd` で 1 段階大きく、`Ctrl+Minus`・`Ctrl+NumSubtract` で 1 段階小さく、`Ctrl+0` で 160、`Escape` と `config.keys.toggle_grid` で `closeGrid()`。それ以外（振り分けキーなど）は false を返して何もしない。移動は絞り込み結果の中で行い、端で止める

**開く:** `pending`/`skipped` なら `closeGrid()` してから `actions.jumpTo(index)`。`moved`/`deleted` なら `toast("この画像はすでに振り分け済みです（取り消しで戻せます）")` だけ
