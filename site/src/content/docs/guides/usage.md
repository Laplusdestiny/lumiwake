## 1. 振り分け先を登録する

初めて起動したら、右上の設定ボタン（または <kbd>Ctrl</kbd>+<kbd>,</kbd>）から **キー割り当て** を開き、振り分け先のフォルダとキーを登録します。

- **＋ 振り分け先を追加**: フォルダを 1 つ選んで追加します。キーは空いているもの（1〜9, 0, Ctrl+1 …）が自動で割り当てられます
- **フォルダ内のサブフォルダをまとめて追加**: 親フォルダを選ぶと、その直下のフォルダをまとめて登録します
- キーの欄をクリックしてキーを押すと、割り当てを変更できます

<img class="shot" src="/lumiwake/settings-keys.webp" width="1600" height="1038" loading="lazy" alt="設定のキー割り当て画面。キー・表示名・パスの一覧で、Shift+8 などの修飾キーも使え、同じ名前の「その他」フォルダはパスで区別できる" />

必要なら **一般** で削除フォルダを指定します（[安全のしくみ](/lumiwake/reference/safety/) を参照）。

## 2. 仕分け元のフォルダを読み込む

仕分けたい画像が入ったフォルダを選び、**読み込んで開始**（<kbd>Enter</kbd>）を押します。サブフォルダの画像も含めるかを選べます。仕分け元の中にある振り分け先フォルダと削除フォルダは、自動で読み込み対象から外れます（振り分け済みの画像がまた出てこないように。外した振り分け先があれば、読み込み後に知らせます）。振り分け直したいときや、振り分け済みの画像も含めて類似画像を確かめたいときは、**振り分け先フォルダの画像も含める** にチェックを入れてください。削除フォルダは常に読み込みません。画像はファイル名順に並びます。更新日時・撮影日時・ファイルサイズの順にしたい場合は **一般 → 読み込み → 並び順** で変えられます。

<img class="shot shot--narrow" src="/lumiwake/start-screen.webp" width="1282" height="832" loading="lazy" alt="開始画面。仕分け元フォルダの入力欄と選択ボタン、最近使ったフォルダの一覧、「サブフォルダの画像も含める」のチェックボックス、「読み込んで開始」ボタン" />

最近使ったフォルダ（10 件まで）は開始画面に一覧で表示され、クリックか <kbd>↑</kbd> <kbd>↓</kbd> で選べます。不要になったものは × で履歴から外せます（フォルダそのものは消えません）。

## 3. キーで振り分ける

<img class="shot" src="/lumiwake/sort-in-progress.webp" width="1600" height="1038" loading="lazy" alt="仕分け途中の画面（24 枚中 5 枚目）。振り分け先リストに各フォルダへ移した枚数が表示され、下のサムネイル列には処理済みの画像に「→風景」などの移動先が付いている" />

| キー（既定） | 操作 |
| --- | --- |
| 登録したキー | その振り分け先へ移動して次へ |
| <kbd>Space</kbd> | スキップ（保留。ファイルは動かさない） |
| <kbd>Delete</kbd> | 削除（削除フォルダへ移動、または削除予定として記録） |
| <kbd>←</kbd> / <kbd>→</kbd> | 前後の画像へ（処理済みの画像は飛ばす） |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 取り消し（何段でも） |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | サイドバー型 ⇔ 全画面型の切り替え |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | 振り分け先リストのパス表示の切り替え（リストの「パスを隠す」ボタンでも可） |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd> | 一覧表示を開く／閉じる（上部の一覧ボタンでも可） |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | 類似画像の確認を開く／閉じる（上部の類似画像ボタンでも可） |
| <kbd>Esc</kbd> | 全画面型を抜ける／ダイアログを閉じる |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | 終了 |

右側の一覧には、振り分け先の名前と **フルパス** が表示されます。同じ名前のフォルダがあってもパスで区別できます。

### 表示モード

プレビューと振り分け先リストを並べる **サイドバー型** と、画像を大きく表示して振り分けキーを下部にまとめる **全画面集中型** を、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> で切り替えられます。

### 一覧表示

仕分け元にたくさんの画像があって目当ての 1 枚を探したいときは、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>（または上部の一覧ボタン）で読み込んだ画像を一覧で表示できます。画像を選んで <kbd>Enter</kbd>（またはクリック）を押すと 1 枚表示に戻り、その画像をそのまま振り分けられます。

| キー | 操作 |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> / <kbd>PageUp</kbd> <kbd>PageDown</kbd> / <kbd>Home</kbd> <kbd>End</kbd> | 画像を選ぶ |
| <kbd>Enter</kbd> | 選んだ画像を開く |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | ファイル名で絞り込む（絞り込み欄で <kbd>Enter</kbd> か <kbd>↓</kbd> を押すと一覧に戻る） |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> | サムネイルを大きく／小さく（4 段階。<kbd>Ctrl</kbd>+ホイールでも可） |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | サムネイルを元の大きさに戻す |
| <kbd>Esc</kbd> | 元の画面に戻る |

- サムネイルの大きさは上部のスライダーでも自由に変えられ、次回も同じ大きさで表示します
- 振り分け済みの画像も薄く表示し、移動先（「→風景」など）や「削除予定」を表示します。振り分け済みの画像は開けないので、<kbd>Ctrl</kbd>+<kbd>Z</kbd> で取り消してから振り分け直してください
- 一覧表示では振り分け・削除・スキップのキーは効きません

### 類似画像の確認

同じ画像を二重に保存していたり、ほぼ同じ構図の写真が何枚もあったりするときは、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd>（または上部の類似画像ボタン）で、仕分け元の中の似た画像をグループごとに並べて確認できます。振り分ける前に、不要なほうを削除予定にしておけます。

Lumiwake は候補を示すだけで、自動では削除しません。あらかじめ画像が選ばれていることもありません。

| キー（既定） | 操作 |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | グループの中で画像を選ぶ |
| <kbd>↑</kbd> <kbd>↓</kbd> / <kbd>Home</kbd> <kbd>End</kbd> | 前後のグループ／最初・最後のグループへ |
| <kbd>Delete</kbd> | 選んだ 1 枚を削除予定にする |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> | **これだけ残す**（選んだ 1 枚を残し、同じグループの残りを削除予定にする） |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 取り消し（1 枚ずつ） |
| <kbd>Space</kbd> | **拡大して比較**（選んだグループを大きく並べる。グループ見出しのボタンでも可） |
| <kbd>Enter</kbd> | 選んだ画像を 1 枚表示で開く（ダブルクリックでも可） |
| <kbd>Esc</kbd> | 元の画面に戻る |

**拡大して比較** では、選んだグループの画像を画面いっぱいに並べて見比べられます（4 枚以上のグループは、選んだ画像を中心に 3 枚ずつ）。削除・これだけ残す・取り消しのキーはそのまま使えます。

| キー | 操作 |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | グループの中の画像を送る |
| <kbd>↑</kbd> <kbd>↓</kbd> | 比較したまま前後のグループへ |
| <kbd>Tab</kbd> | 並べて表示 ⇔ 1 枚ずつ切り替える（同じ場所で画像が入れ替わるので、違いを目で追いやすい） |
| ホイール / <kbd>Ctrl</kbd>+<kbd>=</kbd> <kbd>Ctrl</kbd>+<kbd>-</kbd> | 拡大／縮小。並べた画像は同じ倍率・同じ位置で連動する |
| ドラッグ | 拡大中の画像を動かす |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | 全体表示に戻す |
| <kbd>Esc</kbd> / <kbd>Space</kbd> | グループの一覧に戻る |

- **似ているかどうかは画像の中身で判定します。** 縮小・再圧縮されたもの、ノイズが乗ったもの、隅にマークが入ったものは同じグループになります。構図が大きく違う写真や、切り抜き・回転したものは対象外です
- 上部のスライダーで、どこまで似ていれば同じグループにするか（類似度 75〜100%）を変えられます。値は次回も使います
- グループには根拠が付きます: **完全一致**（ファイルの中身がまったく同じ）、**サイズが同じ**、**解像度が同じ**、**名前が似ている**（`a.jpg` と `a (1).jpg`、連番など）。根拠で絞り込むこともできます
- 画像には「解像度が最大」「サイズが最大」の目印と、グループ内でいちばん近い画像との類似度を表示します。どれを残すかの参考にしてください
- ここでの削除も、削除キーと同じ扱いです（削除フォルダへ移動、または削除予定として記録）。完全に削除するのは終了時の確認後だけです
- 対象は、まだ振り分けていない画像（保留を含む）です。はじめて開いたときは全画像を読むため、判定に少し時間がかかります（進み具合を上部に表示します）。判定の途中でも、見つかったグループから確認・削除を進められます

## 4. 同じ名前のファイルがあったら

移動先に同名のファイルがあると、2 枚の画像が並んで表示されます。

| キー | 選択 | 結果 |
| --- | --- | --- |
| <kbd>1</kbd> | 既存を残す | 移動しようとした画像は削除予定にする |
| <kbd>2</kbd> | 上書き | 既存のファイルは削除予定にする（すぐには消さない） |
| <kbd>3</kbd> | 両方残す | 移動する画像を `名前 (2).jpg` のようにリネームして移動 |
| <kbd>4</kbd> | スキップ | 今回は移動しない |

## 5. 終了する

削除予定のファイルがある場合、終了時に一覧が表示されます。場所を開いて中身を確かめてから、**完全に削除して終了** か **削除せずに終了** を選びます。
